# Tutorials

A tutorial teaches the library by building something that works.

There is no tutorial yet.
A credential issuer that issues nothing is not something to learn from, and no credential format adapter is written: the protocol carries the credential, but something has to produce it.

When the first adapter lands, the tutorial will walk you through issuing a student credential into a test wallet, from the Credential Offer to the credential on the device.

Until then, {doc}`../how-to/serve-the-issuer-endpoints` shows how the pieces fit together, and {doc}`../explanation/what-this-library-decides` explains where the boundary runs.
